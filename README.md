# WarehouseRobot

## Складской робот
2D-аркада. Робот перевозит детали со склада в зону разгрузки.

## Правила
- За один раз робот перевозит только ОДНУ деталь.
- Доставка засчитывается только в зоне разгрузки (Delivery Zone).
- Победа: доставлено 5 деталей.
- Поражение: 3 касания опасной зоны.

## Стек
Unity 6000.5.4f1, C#, 2D Physics, OnGUI, Git.
Управление: WASD / стрелки + экранные кнопки. R — перезапуск.

## Структура
Assets/Scenes — сцена Main
Assets/Scripts — игровые скрипты
Assets/Documentation — отчёт и скриншоты
